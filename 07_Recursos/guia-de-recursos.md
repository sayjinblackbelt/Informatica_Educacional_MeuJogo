# Guia de Recursos

## Finalidade

Estabelecer critérios para selecionar recursos pedagógicos, digitais e multimídia utilizados no projeto.

## 1. Relevância pedagógica

Antes de adicionar um recurso, verificar:

- qual objetivo ele atende;
- para qual atividade será utilizado;
- qual competência pretende desenvolver;
- se existe alternativa mais simples;
- se é acessível ao nível da turma.

## 2. Independência de plataforma

Sempre que possível, preferir recursos que não dependam de uma única plataforma, conta, sistema operacional ou dispositivo.

Registrar a finalidade do recurso, e não apenas o nome da ferramenta.

## 3. Direitos autorais

Não assumir que um material encontrado na internet é livre para reutilização. Verificar domínio público, licença ou autorização de uso.

## 4. Acessibilidade

Priorizar recursos que:

- tenham boa legibilidade;
- funcionem com diferentes formas de interação;
- ofereçam instruções claras;
- permitam adaptação;
- não dependam exclusivamente de áudio, cor ou texto.

## 5. Privacidade

Não publicar recursos contendo:

- nomes de educandos;
- contatos;
- fotografias identificáveis;
- documentos pessoais;
- notas ou avaliações individuais;
- informações que permitam identificar participantes.

## 6. Organização

Nomear arquivos de forma clara e consistente. Para materiais relacionados às aulas, utilizar o padrão geral de nomenclatura definido para o projeto quando aplicável.

## 7. Ciclo de revisão

**Selecionar → Verificar → Adaptar → Testar → Registrar → Revisar**

Recursos antigos devem ser revisados periodicamente para confirmar funcionamento, adequação pedagógica e licenciamento.
