# 05 — Grupos

## Finalidade

Registrar projetos e produções coletivas de forma sanitizada, preservando a autoria pedagógica dos trabalhos sem expor a identidade dos participantes.

## Identificação pública

Os grupos devem utilizar identificadores neutros:

- `grupo_01`
- `grupo_02`
- `grupo_03`
- etc.

Nomes de personagens, mundos, cidades e histórias criados pelos participantes **não são dados pessoais** e podem permanecer quando fizerem parte da produção autoral.

## Estrutura

Cada grupo pode conter:

```text
grupo_XX/
├── projeto.md
├── historia.md
└── outros-recursos/
```

A estrutura pode variar conforme o projeto.

## O que registrar

- conceito do projeto;
- propósito;
- personagem;
- mundo;
- problema;
- desafios;
- escolhas;
- narrativa;
- mecânicas;
- protótipos;
- evolução do projeto;
- reflexões coletivas.

## O que não registrar

Não publicar:

- nomes completos dos participantes;
- apelidos que permitam identificação;
- fotografias identificáveis;
- contatos;
- avaliações individuais;
- frequência;
- informações pessoais;
- credenciais.

## Sanitização

Antes de publicar um novo projeto:

1. substituir identificação pessoal por `grupo_XX`;
2. remover dados de contato;
3. revisar imagens e anexos;
4. verificar links privados;
5. verificar secrets;
6. conferir se o conteúdo autoral continua preservado.

## Princípio pedagógico

O foco público deve estar no **processo criativo e no produto desenvolvido**, não na exposição dos participantes.

> **Preservar a produção sem expor a pessoa.**
