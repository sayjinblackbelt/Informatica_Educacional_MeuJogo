# 08 — Tecnologia

## Finalidade

Registrar os recursos tecnológicos utilizados ou previstos no projeto, priorizando função pedagógica, autonomia e segurança em vez de dependência de marcas ou plataformas específicas.

## Ambiente computacional

- computador disponível para cada educando, sempre que possível;
- sistema operacional disponível no laboratório;
- gerenciador de arquivos;
- navegador web;
- editor de texto;
- ferramentas de apresentação;
- recursos de criação digital.

## Ferramentas por função

| Função | Recurso principal | Alternativa |
|---|---|---|
| Digitação e texto | Editor de texto | Editor local equivalente |
| Organização | Gerenciador de arquivos | Ferramenta equivalente |
| Pesquisa | Navegador web | Outro navegador compatível |
| Apresentação | Ferramenta de apresentações | Editor equivalente |
| Colaboração | Plataforma colaborativa disponível | Ferramenta institucional equivalente |
| Criação visual | Editor gráfico disponível | Alternativa compatível |
| Criação de jogos | Ferramenta de autoria disponível | Outra ferramenta adequada ao objetivo |

> Nomes de produtos podem mudar. A documentação deve priorizar a competência desenvolvida e registrar a ferramenta específica apenas quando isso for relevante para reprodução da atividade.

## Critérios de seleção

Uma ferramenta deve ser avaliada segundo:

1. relevância pedagógica;
2. facilidade de acesso;
3. adequação ao público;
4. acessibilidade;
5. segurança e privacidade;
6. estabilidade;
7. custo e disponibilidade;
8. possibilidade de exportar ou preservar o trabalho;
9. existência de alternativa.

## Contas e dados

Não registrar no repositório:

- senhas;
- tokens;
- chaves de API;
- links privados;
- dados de acesso;
- dados pessoais de educandos.

Segredos devem ser armazenados em mecanismos apropriados, nunca diretamente no código ou em arquivos públicos. citeturn0search6

## Dependências

Antes de adicionar uma biblioteca, serviço ou plataforma:

- verificar se é realmente necessária;
- identificar a licença, quando aplicável;
- avaliar manutenção e segurança;
- documentar a finalidade;
- evitar dependências desnecessárias.

## Compatibilidade

Sempre que possível, as atividades devem possuir uma alternativa caso determinada plataforma esteja indisponível.

**Princípio:** a tecnologia é meio para a aprendizagem, não o objetivo da atividade.
