## Critério de status

“Link informado” significa que o endereço foi registrado, não que todas as mecânicas tenham sido testadas. Atualizar o status somente após abrir o jogo e registrar evidências de funcionamento.

## Privacidade e autoria

A documentação pública utiliza apenas os primeiros nomes fornecidos para os créditos. Não adicionar nomes completos, fotografias identificáveis, dados de contato, avaliações individuais ou outros dados pessoais. Não atribuir projetos a Apolo, Amanda ou outros educandos sem confirmação explícita.
