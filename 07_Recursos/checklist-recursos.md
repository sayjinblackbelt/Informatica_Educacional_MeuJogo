# Checklist de Recursos

Antes de adicionar ou publicar um recurso, verificar:

## Pedagogia
- [ ] Possui objetivo pedagógico claro.
- [ ] É adequado ao nível da turma.
- [ ] É realmente necessário.
- [ ] Pode ser adaptado se houver diferentes níveis de aprendizagem.

## Tecnologia
- [ ] Funciona no ambiente disponível.
- [ ] Não depende desnecessariamente de uma única plataforma.
- [ ] Possui alternativa quando a ferramenta principal não estiver disponível.

## Direitos autorais
- [ ] A origem foi identificada.
- [ ] A licença ou autorização foi verificada.
- [ ] Atribuição foi registrada quando necessária.
- [ ] O material não foi copiado integralmente sem permissão.

## Privacidade
- [ ] Não contém dados pessoais de educandos.
- [ ] Não contém avaliações individuais.
- [ ] Não contém fotografias identificáveis sem autorização.
- [ ] Não expõe informações institucionais desnecessárias.

## Publicação
- [ ] O nome do arquivo está padronizado.
- [ ] O conteúdo foi revisado.
- [ ] O recurso está no diretório correto.
- [ ] A documentação explica sua finalidade.
